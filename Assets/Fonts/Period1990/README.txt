FrontRooms - period type kit (1988-93 furniture ads, shelter magazines, TV shopping)

Every file here is free to embed in the game: SIL OFL 1.1 (OFL.txt), GUST Font License
(TeX Gyre) or Apache 2.0 (Yellowtail). Licence files sit next to each family.

These are game-safe stand-ins for the period faces found in the research
(Helvetica, Futura, ITC Garamond, Goudy, Cheltenham, Avant Garde, Friz Quadrata,
Cooper Black, Eurostile, Didot/Bodoni ...). Which file replaces which period face,
and the settings to use: Documentation/FONTS_PERIOD_1990.md

Static cuts only: Unity imports a variable font at its default instance, so the
condensed / expanded / soft cuts were baked as separate .ttf files.
This folder is outside Resources/, so nothing ships unless a scene or asset uses it.
TextMeshPro: Window > TextMeshPro > Font Asset Creator, pick the .ttf, save the SDF asset here.
Variable originals and specimens: Research/week02/furniture-ads/fonts (outside the Unity project).
